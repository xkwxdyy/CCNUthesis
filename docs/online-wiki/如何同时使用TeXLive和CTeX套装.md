# 如何同时使用 TeXLive 和 CTeX 套装？（Windows系统）

有时用户安装 `TeXLive` 的时候并不想卸载 CTeX 套装，出于（但不限于）以下几个原因：
1. 为了保险，仍然希望可以使用邓的旧模版
2. 有投中文核心期刊的需求
3. 课题组内（甚至包括老师）大部分使用的模版都是 CTeX套装写的，但自己不会改
4. ...

所以本文档希望能够分享一种在 Windows 系统上同时安装 `TeXLive` 和 CTeX 套装并都能正常使用的方法。

## 安装 `TeXLive` 和 CTeX 套装

- CTeX套装安装网址：<https://ctex.org/CTeX/download/>
- `TeXLive` 安装，见 <https://mirrors.tuna.tsinghua.edu.cn/CTAN/info/install-latex-guide-zh-cn/install-latex-guide-zh-cn.pdf> 及[install-latex-guide-zh-cn 文档补充](./install-latex-guide-zh-cn文档补充.md)

C:/texlive/2023/bin/windows

mactex
